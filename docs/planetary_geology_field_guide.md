# Orbital Ante --- Planetary Geology Field Guide

Oct 30, 2026 · \@Matthew

## How to use this guide

This is a catalog of about 170 real landforms, grouped by the process
that makes them, each with a game use and a reference image link. Part 8
assigns them to Orbital Ante\'s fixed solar system, and Part 9 is a
copy-paste prompt that turns the catalog into per-planet feature kits
for procedural placement.

Each catalog row has four columns: the feature, what it physically is,
how it can play in Orbital Ante (driving, flying, cover, loot spots,
hazards), and a reference image. Image links point to public-domain or
scientific image libraries (NPS, USGS, NASA/JPL) where possible, and to
the Wikimedia Commons gallery for that landform otherwise. NPS, USGS and
NASA photos are generally public domain, which suits your concept-art
and Tripo pipeline; check each image\'s credit line before reuse.

## 2. Erosional desert and sedimentary features

This is the richest set for hoodoo-and-mesa planets like Mars and
Mercury. Per the NPS, Bryce Canyon holds the world\'s largest
concentration of hoodoos, alongside fluted cliffs, spires, windows and
arches formed along rock fractures
([NPS](https://www.nps.gov/articles/nps-geodiversity-atlas-bryce-canyon-national-park.htm)).
Mesas are usually wider than tall, buttes taller than wide, and towers
and hoodoos are further-eroded stages ([NPS Petrified
Forest](https://www.nps.gov/pefo/learn/nature/naturalfeaturesandecosystems.htm)).
Use that erosion sequence (plateau → mesa → butte → spire → hoodoo) to
cluster features believably.

## 3. Karst, caves and grottos

Caves are your best loot and horror spaces. The NPS describes karst as
landscapes dissolved out of limestone, dolomite and gypsum, marked by
sinkholes, caves, springs and sinking streams, and lists four cave
families: solution, volcanic, erosion and ice caves ([NPS
poster](https://www.nps.gov/subjects/caves/upload/2014_caveandkarstnpsPoster_LRes.pdf)).
On non-Earth bodies, swap limestone for ice or lava to keep it
plausible.

**Placement rules** (matches your procedural direction)

1.  Fixed per body: the signature landmarks and their rough location
    stay the same every run, so players learn the system.

2.  Seeded: set pieces are placed from the body\'s kit, with spacing and
    slope rules; filler props scatter by biome.

3.  Clustering: place features in their real erosion or formation
    sequences (plateau → mesa → butte → hoodoo; cave → arch → stack;
    cirque → tarn → moraine), never as random singles.

4.  Water bodies: pick a lake type from Part 5 and use its shape cue so
    lakes differ in outline, depth and shore.

5.  Craters: weight crater density by body age --- high on Moon, Mercury
    and asteroids, low on Earth and Venus.

6.  Gameplay hooks: tag every set piece with what it supports (landing,
    rover route, cover, cave interior, oxygen-tank spot, chest spot,
    base site, horror zone).
