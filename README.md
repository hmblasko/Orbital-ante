# Orbital Ante (working title)

First-person space-exploration roguelite for Steam Deck. Unity 6 LTS, URP, C#.

- `docs/BUILD_PROMPT.md`: the master build prompt (source of truth)
- `docs/SETUP.md`: install Unity, open the project, run setup, play the test arena
- `docs/DECISIONS.md`: open questions and the current answers
- `docs/milestones/`: what each milestone delivered and how to playtest it

Current state: **Milestone 0 (test arena + pause menu) and Milestone 1 (breakable mannequin)**.
The previous Godot + Rust build is on the `archive/godot-rust` branch.
